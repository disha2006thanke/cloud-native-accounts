
# Cloud Native Accounts

A DevOps Capstone project for managing customer accounts using a RESTful microservice.

## Project Overview

This project demonstrates customer account management and DevOps practices, including automated testing, continuous integration, containerization, and Kubernetes deployment.

## Features

- Create a customer account
- List all customer accounts
- Retrieve an account by ID
- Update account details
- Delete a customer account
- Automated testing and code quality checks
- Security headers and CORS configuration
- Docker containerization
- Kubernetes deployment
- CI/CD pipeline automation

## Technology Stack

- Python
- Flask
- SQLite
- Git and GitHub
- GitHub Actions
- Docker
- Kubernetes
- Tekton

## Build Status

The build status badge will be added after the GitHub Actions workflow is configured and a successful build has completed.

## Running the Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
python app.py
```

## Testing

Run the configured automated tests using the project's test instructions.

## Project Purpose

The purpose of this project is to demonstrate the development, testing, security, containerization, and deployment of a cloud-native customer accounts microservice.
